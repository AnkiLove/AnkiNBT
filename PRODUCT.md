# Product

## Register

brand

## Users

AnkiNBT users are Minecraft creative-mode players, map makers, modpack maintainers and technical players who need a fast reference for installing the mod and editing item or entity data without guessing version details.

## Product Purpose

The documentation site explains what AnkiNBT does, which loader and Minecraft versions it supports, how to install it, and how to use simple and advanced editing modes. Success means users can pick the right jar, open the editor, find the right feature, and understand the release notes without switching between scattered documents.

## Brand Personality

Precise, energetic, tool-focused. The site should feel like a sharp modding console with clear signposts, not a generic SaaS landing page.

## Anti-references

Avoid oversized template hero cards, repeated identical feature cards, mixed-language navigation, vague marketing copy, decorative glass effects, and pages that look AI-generated or detached from Minecraft modding.

## Design Principles

- Split by language first: Chinese and English should have matching structures, but independent labels and page URLs.
- Lead with action: install, start editing, check compatibility, then dig into details.
- Keep the tool visible: show the logo and editor concepts, but do not let artwork overpower documentation.
- Make version confidence obvious: loaders, Java versions and release notes should be visible early.
- Use restrained motion and color: cyan is the default identity, pink is used only for release/fix emphasis.

## Accessibility & Inclusion

Target readable contrast in both dark and light modes, avoid color-only meaning, respect reduced motion, keep body text under 75 characters per line, and keep navigation scannable for Chinese and English readers.
