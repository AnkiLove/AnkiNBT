# AnkiNBT

一个客户端侧的 Minecraft NBT 编辑器，同时支持 NeoForge 和 Fabric，兼容 1.21 ~ 1.21.11 全版本。

纯客户端运行，服务端无需安装任何内容。按 `N` 键即可打开编辑器，编辑完成后 `Ctrl+S` 保存。

---

### 功能概览

- 纯客户端，不依赖服务端
- 提供简易模式（可视化）和高级模式（NBT 树）两种编辑方式
- 中英双语，自动跟随游戏语言设置
- 半透明暗色界面，风格简洁
- 支持主手物品和背包悬停物品编辑
- 创造模式下可保存修改，其他模式仅供查看

---

### 简易模式

面向不熟悉 NBT 结构的用户。左侧为分类导航，右侧为属性列表，点击即可编辑。

- 基础属性 — 物品名称、数量、耐久、最大堆叠、修复花费、稀有度、无法破坏、防火、饱食度/饱和度
- 附魔 — 添加、删除、调整等级，支持中文搜索，可一键清除全部附魔
- 描述 (Lore) — 逐行编辑，支持 `&c` `&l` 等颜色/格式代码，内置色板选择器，编辑时实时预览
- 属性修饰 — 攻击力、护甲、移动速度等，支持三种运算模式和槽位选择，带中文搜索
- 外观 — 自定义模型数据、附魔光效、隐藏提示框、染色颜色、物品名称颜色
- 工具 — 复制 NBT 到剪贴板、复制 `/give` 指令、重置为原始物品

---

### 高级模式

完整的 NBT 树编辑器，可查看和修改物品的全部数据组件。

- 树形结构展示，不同标签类型以颜色区分
- 支持按键名、值或类型进行搜索过滤
- 全部展开 / 全部折叠
- 可新建任意 NBT 类型的标签
- 双击或 `Enter` 编辑值，输入时自动校验类型
- `Delete` 键删除节点
- 侧边栏显示物品 ID、数量、组件数量

---

### 安装方法

1. 安装对应 MC 版本的 NeoForge 或 Fabric（Fabric 需同时安装 Fabric API）
2. 将 JAR 文件放入 `.minecraft/mods/` 目录
3. 启动游戏即可

---

### 使用方式

手持物品按 `N` 打开编辑器，或在背包界面将鼠标悬停在物品上按 `N`。

注意：仅创造模式下可保存修改，其他游戏模式下编辑器为只读状态。

---

### 快捷键

| 按键 | 功能 | 适用模式 |
|:----:|:-----|:-------:|
| `N` | 打开编辑器（可在 控制 > AnkiNBT 中自定义） | 通用 |
| `Ctrl+S` | 保存修改 | 通用 |
| `Esc` | 关闭编辑器 | 通用 |
| 双击 | 编辑值 / 展开折叠 | 高级模式 |
| `E` | 展开 / 折叠节点 | 高级模式 |
| `Enter` | 编辑选中值 | 高级模式 |
| `Delete` | 删除选中标签 | 高级模式 |
| `↑` `↓` | 上下导航 | 高级模式 |

### 项目结构

```
AnkiNBT/
├── src/                    # 共享核心代码 + NeoForge 主入口
├── versions/               # NeoForge 各版本适配 (1.21 ~ 1.21.11)
├── fabric/                 # Fabric 主版本 (1.21.1)
├── fabric-versions/        # Fabric 各版本适配 (1.21 ~ 1.21.11)
├── build.gradle            # NeoForge 根构建脚本
├── gradle.properties       # NeoForge 构建参数
└── README.md
```

分支说明：
- `main` — 完整项目，包含 NeoForge 和 Fabric 全部代码
- `neoforge` — 仅 NeoForge 相关代码
- `fabric` — 仅 Fabric 相关代码

### 从源码编译

环境要求：JDK 21

NeoForge（以 1.21.1 为例）：

```bash
cd versions/1.21.1
gradlew build
```

Fabric（以 1.21.1 为例）：

```bash
cd fabric
gradlew build
```

其他版本同理，进入对应的 `versions/<版本号>` 或 `fabric-versions/<版本号>` 目录执行 `gradlew build` 即可。

编译产物在各子目录的 `build/libs/` 下。

注意：`gradle.properties` 中的代理配置（`proxyHost`/`proxyPort`）是开发环境的本地设置，编译前请根据自己的网络环境修改或删除。
