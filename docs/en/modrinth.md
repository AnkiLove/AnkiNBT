# Modrinth Copy

AnkiNBT is a client-side Minecraft NBT editor for creative-mode workflows, with Fabric and NeoForge support.

## Who It Helps

- Map makers
- Modpack maintainers
- Players who need quick item and entity data edits

## Core Features

- Simple Mode: common item fields, lore, enchantments, attributes and potion effects
- Advanced Mode: inspect, search, add, remove and edit the NBT tree
- Item picker: search by name and namespace
- NBT import and export: save and reuse edited data

## Compatibility

Supports Minecraft 1.21 through 1.21.11, plus 26.1 through 26.1.2. Fabric builds require Fabric API.
