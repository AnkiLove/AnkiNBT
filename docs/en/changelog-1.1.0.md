# AnkiNBT 1.1.0 Changelog

## Added

- Visual entity editor for names, health, movement speed, attack damage and common entity flags.
- Villager trade editor for existing villagers and villager spawn egg trade data.
- Configuration menu for editor preference, UI style, keybinds and debug options.
- Item picker with recent items for faster editing workflows.
- Container content editing entry points for container items.

## Improved

- Unified the editor interface with a clearer modern translucent theme.
- Improved switching between Simple Mode and Advanced Mode.
- Expanded Chinese and English localization coverage.

## Compatibility

- Expanded multi-version support across the NeoForge and Fabric 1.21 series.
- Strengthened the cross-version compatibility layer to reduce API breakage across minor versions.
