## 支持范围

| 加载器 | Minecraft 版本 | Java |
|---|---|---|
| Fabric | 1.21 ~ 1.21.11、26.1、26.1.1、26.1.2 | Java 21 / Java 25 |
| NeoForge | 1.21 ~ 1.21.11、26.1、26.1.1、26.1.2 | Java 21 / Java 25 |

1.21 系列使用 Java 21，26.1 系列使用 Java 25。
