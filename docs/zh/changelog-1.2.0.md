# AnkiNBT 1.2.0 更新日志

## 新增
- 新增实体可视化编辑增强：支持更完整的属性编辑、实时预览、血量一键补满与状态开关编辑。
- 新增村民交易编辑增强：支持新增/删除交易、职业与等级控制、交易项快捷选取与主手填充。
- 新增配置菜单分页：`通用`、`按键`、`界面`、`高级`、`调试`，并支持实时调试日志面板。
- 新增物品选择器与自定义分组可视化编辑（分组增删改、顺序调整、分组内物品管理）。
- 新增界面交互音效与音量配置项。

## 改进
- 重构简易编辑、实体编辑、村民编辑与配置界面的布局与样式，统一为现代化卡片式交互风格。
- 优化按钮状态反馈、未保存变更确认流程与关键操作路径。
- 优化按键绑定显示逻辑，避免按键名称异常显示（如 `#78/#79`）。
- 优化物品选择与列表类界面的滚动体验与可操作性。

## 修复
- 修复 1.21.11 下部分界面渲染崩溃（`Can only blur once per frame`）。
- 修复实体编辑中血量应用不稳定、上限提示缺失等问题。
- 修复村民交易在不同目标来源下（现有实体/刷怪蛋）的读取与应用兼容问题。
- 修复容器编辑入口显示与可用条件判断问题（仅在可编辑容器场景显示）。
- 修复跨小版本 API 差异导致的若干编译失败与运行时兼容问题。

## 兼容性
- 支持 NeoForge / Fabric 双端。
- 覆盖 Minecraft `1.21` 至 `1.21.11`（通过版本适配层统一维护）。
