# AnkiNBT 维基

欢迎来到 **AnkiNBT** 维基 — 一个现代化的 Minecraft 客户端 NBT 编辑器模组。

AnkiNBT 支持 **NeoForge** 和 **Fabric**，覆盖 Minecraft **1.21 ~ 1.21.11**、**26.1 ~ 26.1.2**。

线上文档地址：<https://rabbit-6.gitbook.io/ankinbt-wiki>

---

## 主要特性

- **双编辑模式** — 简易模式（可视化）+ 高级模式（NBT 树）
- **半透明暗色 UI** — 现代简洁设计
- **灵活的物品选择** — 支持主手持物品或背包悬停物品编辑
- **创造模式保存** — 创造模式下可保存修改，其他模式仅查看
- **NBT 文件导入/导出** — 支持自定义路径和分类管理
- **未保存更改保护** — 关闭时弹出确认对话框
- **Lore 编辑器** — 多行文本编辑器，支持颜色代码和内置色板
- **药水效果编辑** — 支持多选，并可单独调整每个效果
- **物品选择器搜索** — 选择物品时可以按名称或命名空间过滤
- **中英双语** — 自动跟随游戏语言设置

## 支持版本

| 平台 | 版本 |
|------|------|
| NeoForge | 1.21 ~ 1.21.11、26.1、26.1.1、26.1.2 |
| Fabric   | 1.21 ~ 1.21.11、26.1、26.1.1、26.1.2 |

**环境要求：**

- 1.21 系列：Java 21
- 26.1 系列：Java 25
