# AnkiNBT 1.1.0 更新日志

## 新增
- 新增实体可视化编辑器：可修改名称、血量/最大血量、移动速度、攻击伤害及常用实体标志位。
- 新增村民交易编辑器：支持编辑现有村民与村民刷怪蛋交易数据。
- 新增配置菜单：支持编辑器偏好、UI 风格、按键与调试相关设置。
- 新增物品选择器与最近使用分组，支持在编辑流程中快速选物品。
- 新增容器内容编辑入口（容器类物品可直接预览/修改内容）。

## 改进
- 界面风格统一为现代化半透明主题，编辑布局更清晰。
- 简易编辑与高级编辑之间的切换体验优化。
- 中英文本地化覆盖范围扩大，按游戏语言自动切换。

## 兼容性
- 扩展多版本支持，覆盖 NeoForge / Fabric 的 1.21 系列版本。
- 增强跨版本 API 兼容层，降低不同小版本差异带来的功能失效概率。
