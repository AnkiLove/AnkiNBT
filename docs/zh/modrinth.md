# Modrinth 介绍

AnkiNBT 是一个面向 Minecraft 创造模式的客户端 NBT 编辑器，支持 Fabric 和 NeoForge。

## 适合谁

- 地图作者
- 模组包维护者
- 需要快速调试物品和实体数据的玩家

## 核心功能

- 简易模式：常用物品属性、Lore、附魔、属性修饰和药水效果
- 高级模式：NBT 树查看、搜索、添加、删除和修改
- 物品选择器：按名称和命名空间搜索
- NBT 导入导出：保存和复用编辑结果

## 兼容

支持 Minecraft 1.21 到 1.21.11，以及 26.1 到 26.1.2。Fabric 版本需要 Fabric API。
