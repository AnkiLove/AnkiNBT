# 简易模式

简易模式是一个可视化编辑器，专为不需要了解 NBT 知识的用户设计。左侧为分类导航栏，右侧为属性列表。

---

## 界面布局

- **左侧边栏** — 分类导航（基础属性、附魔、描述、属性修饰、外观、工具）
- **右侧面板** — 所选分类的属性列表
- **顶部标题栏** — 物品名称、模式切换（简易/高级）、保存按钮
- **底部状态栏** — 状态消息

---

## 分类详解

### 基础属性

编辑物品的基本属性：

| 属性 | 说明 |
|------|------|
| **物品名称** | 自定义显示名称 |
| **数量** | 堆叠数量 |
| **耐久** | 当前耐久值 |
| **无法破坏** | 切换无法破坏标记 |
| **最大堆叠数** | 最大堆叠数量 |
| **修复花费** | 铁砧修复花费 |
| **防火** | 物品是否免受火焰/岩浆伤害 |
| **饱食度** | 食物饱食度（仅食物物品） |
| **饱和度** | 食物饱和度（仅食物物品） |
| **稀有度** | 物品稀有度等级（普通、稀有、珍贵、史诗） |

### 附魔

管理物品附魔：

- **查看** 所有当前附魔及其等级
- **编辑** 附魔等级，点击等级值即可修改
- **添加** 新附魔，支持中文搜索
- **删除** 单个附魔
- **一键清除** — 移除所有附魔

!!! info
    附魔列表包含所有原版附魔。可在搜索框中输入中文或英文名称进行筛选。

### 描述 (Lore)

编辑物品描述文本：

- **添加** 新的描述行
- **编辑** 现有行，点击即可修改
- **删除** 行，使用删除按钮
- **上下移动** 调整行顺序
- **颜色代码** — 使用 `&` 颜色代码（如 `&c` 红色、`&l` 粗体）
- **内置色板** — 色板选择器方便选色
- **格式化颜色代码** — 编辑确认后应用颜色与格式代码

### 属性修饰

添加和管理属性修饰符：

- **添加** 修饰符，支持中文搜索全部属性类型
- **属性类型** 包括：攻击伤害、攻击速度、护甲值、护甲韧性、最大生命值、移动速度、击退抗性、幸运值等
- **三种运算模式**：加法、基础乘法、总乘法
- **槽位选择**：选择修饰符生效的装备槽位（任意、主手、副手、头部、胸甲、腿部、脚部）
- **编辑** 现有修饰符的值
- **删除** 单个修饰符

### 外观

自定义物品外观：

| 属性 | 说明 |
|------|------|
| **自定义模型数据** | 资源包自定义模型的整数值 |
| **附魔光效** | 强制开启/关闭附魔光效 |
| **隐藏提示框** | 完全隐藏物品提示框 |
| **染色颜色** | 设置皮革护甲染色颜色（RGB） |
| **物品名称颜色** | 修改显示名称颜色 |

### 工具

实用功能：

| 工具 | 说明 |
|------|------|
| **复制 NBT** | 将完整 NBT 数据复制到剪贴板 |
| **复制 /give 指令** | 生成并复制该物品的 `/give` 指令 |
| **重置物品** | 还原所有修改至原始状态 |
| **导出 NBT** | 将 NBT 数据保存为 `.nbt` 文件（可选分类和别名） |
| **导入 NBT** | 从之前导出的 `.nbt` 文件加载数据 |

#### NBT 文件导入/导出

- 导出的文件默认保存在 `.minecraft/ankinbt-config/save-nbt/`（可配置）。
- 可将导出文件按**分类**（子文件夹）组织管理。
- 每次导出可设置**别名**（友好名称），方便识别。
- 导入界面会列出所有可用的 `.nbt` 文件，显示别名、大小和修改日期。

---

## 使用技巧

- 点击任何可编辑字段即可修改其值。
- 修改不会立即生效，需要按 `Ctrl+S` 保存（仅限创造模式）。
- 可随时通过顶部切换按钮切换到高级模式。
