# Compatibility Matrix (Grouped)

This groups the build outputs into practical version ranges for release/packaging.

## NeoForge
- **1.21–1.21.2**: `mc1.21`, `mc1.21.1`, `mc1.21.2`
- **1.21.3–1.21.8**: `mc1.21.3` to `mc1.21.8`
- **1.21.9–1.21.11**: `mc1.21.9`, `mc1.21.10`, `mc1.21.11`
- **26.1 series**: `mc26.1`, `mc26.1.1`, `mc26.1.2`

## Fabric
- **1.21–1.21.2**: `mc1.21`, `mc1.21.1`, `mc1.21.2`
- **1.21.3–1.21.8**: `mc1.21.3` to `mc1.21.8`
- **1.21.9–1.21.11**: `mc1.21.9`, `mc1.21.10`, `mc1.21.11`
- **26.1 series**: `mc26.1`, `mc26.1.1`, `mc26.1.2`

## Java
- **1.21–1.21.11**: Java 21
- **26.1–26.1.2**: Java 25

## Output Paths
- `output/<timestamp>/NeoForge/mc<version>/AnkiNBT-NeoForge-*.jar`
- `output/<timestamp>/Fabric/mc<version>/AnkiNBT-Fabric-*.jar`
