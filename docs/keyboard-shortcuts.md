# Keyboard Shortcuts

## Global Shortcuts

These work anywhere in the game:

| Shortcut | Action |
|----------|--------|
| `N` | Open editor for held item (configurable in Controls > AnkiNBT) |
| `N` (in inventory) | Open editor for hovered item |

## Editor Shortcuts (Both Modes)

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Save changes to item (Creative Mode only) |
| `Esc` | Close editor (shows confirmation if unsaved changes exist) |

## Advanced Mode Shortcuts

| Shortcut | Action |
|----------|--------|
| `Up` / `Down` arrow | Navigate between tree nodes |
| `E` | Expand or collapse the selected node |
| `Enter` | Edit the selected node's value |
| `Delete` | Remove the selected node |
| Double-click | Edit value (leaf nodes) or expand/collapse (container nodes) |

## Customizing the Open Key

The default key to open the editor is `N`. To change it:

1. Open Minecraft **Options** > **Controls** > **Key Binds**.
2. Find the **AnkiNBT** category.
3. Click on **Open Editor** and press your desired key.
4. The new binding is saved automatically.
